forEach()

Digunakan untuk menjalankan perintah pada setiap data di dalam array.

const siswa = ["Atha", "Haidar", "Iqbal"]; 
siswa.forEach((nama) =>
{console.log("Hadir:", nama);});

find()

Digunakan untuk mencari data pertama yang sesuai dengan kondisi tertentu.

const siswa = [
{ nama: "Amaris", tinggi: 172 },
{ nama: "Anggun", tinggi: 180 }
];
siswa.find((s) => s.tinggi === 172);

some()

Digunakan untuk mengecek apakah setidaknya ada satu data yang memenuhi kondisi.

const stock = [15, 0, 8, 20];
stock.some((n) => n === 0);

every()

Digunakan untuk mengecek apakah semua data memenuhi kondisi tertentu.

const umur = [20, 21, 22];
umur.every((n) => n >= 18);

includes()

Digunakan untuk mengecek apakah suatu nilai terdapat di dalam array. 

const angka = [1, 2, 3, 4, 5];
angka.includes(3);
